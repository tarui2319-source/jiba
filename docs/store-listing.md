JIBA（陣地）は、ターン制の陣取り戦略ゲームです。

【ゲームの流れ】
盤面にアンカーを配置し、シェイプの形にそってパワーを広げます。

【その他の特徴】

・日本語・英語に対応
・完全無料・広告なし・課金なし

シンプルなルールながら、どのシェイプを使うか、どこにアンカーを置くか——
読み合いと陣取りの奥深い戦略ゲームをお楽しみください。

### 詳細な説明（4000文字以内）
```
JIBA（陣地）は、シンプルなルールと奥深い戦略が融合したターン制陣取りゲームです。

■ ゲームの目的
対戦終了時に、相手より多くのマスを支配していれば勝利！

■ アンカーとシェイプの仕組み
盤面のマスにアンカーを設置すると、選んだシェイプの形にそってパワーが広がります。
パワーが高い側がそのマスを支配——ただし、アンカーを置いたマスだけは絶対に奪われません。

■ 7種のシェイプ
弱・中（十字）・中（斜め）・強（縦）・強（横）・強（斜め↖）・強（斜め↗）
シェイプごとにパワーの広がり方が異なり、状況に応じた使い分けが勝負の鍵。

■ 3つの対戦モード
・CPU対戦（4段階の難易度）
・2人対戦（同端末でローカル対戦）
・オンライン対戦（リアルタイムマッチング）

■ 段位システム
勝利で昇段、敗北で降格。初段から名人まで腕を磨こう。

■ 完全無料
広告なし・課金なし・追加購入なし。すべての機能を無料で楽しめます。

日本語・英語対応。
```
